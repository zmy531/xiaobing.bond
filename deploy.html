部署教程
只需要 PHP + 目录写入权限，无需数据库。
从本地预览到上线，最快 2 分钟搞定 ✅

📦 环境要求

🐘
PHP 版本
≥ 7.4（推荐 8.0 / 8.1）无需 PDO / MySQL 等扩展
💾
存储方式
JSON 文件本地存储 无需 MySQL 数据库
📁
写入权限
data/ 和 uploads/ 目录可写
🌐
服务器
Nginx / Apache / IIS / PHP 内置服务器 任意都可以
💡 零依赖：项目所有静态资源（CSS/JS/字体/图标/默认图）都内置在 static/ 目录， 没有任何外部 CDN 或外部脚本，离线 / 内网环境也能完美运行。

🛫 选择你的部署方式

1
安装 PHP（如果没有）
Windows 用户建议安装 phpStudy 小皮面板 或单独下载 PHP（官网）。
macOS / Linux 通常自带或通过 brew install php / apt install php-cli 安装。
2
打开终端，进入项目目录启动内置服务器
# Windows PowerShell / CMD
cd C:\Users\你的名字\Desktop\个人主页上传即用
php -S 127.0.0.1:8080

# macOS / Linux
cd ~/Desktop/personal-homepage
php -S 127.0.0.1:8080
3
浏览器打开即可预览
前台首页：http://127.0.0.1:8080/
后台登录：http://127.0.0.1:8080/admin.html
默认账号：admin / admin
⚠️ 重要：php -S 是 开发用服务器，仅供本地预览，请勿用于生产环境公网部署。
1
宝塔面板 → 网站 → 添加站点
域名：填你的域名（例如 home.example.com）
根目录：默认即可，例如 /www/wwwroot/home.example.com
PHP 版本：选择 7.4 或更高（8.x 最佳）
数据库：不创建（本项目不需要数据库）
如果只是测试玩玩，没有域名可以先用宝塔的 IP:端口 方式访问。
2
上传项目文件到网站根目录
方式 A：宝塔 文件管理 → 进入根目录 → 上传压缩包（zip） → 解压
方式 B：使用 FTP / SCP / SFTP 上传所有文件到根目录
✅ 正确结果：根目录下能直接看到 index.html、api/、static/ 等文件夹，不是嵌套一层文件夹！
3
设置目录权限（重要！否则上传会失败）
在宝塔文件管理器，选中 data/ 和 uploads/ 两个目录（按住 Ctrl 多选）→ 右键 权限 → 设置为 755，所有者 www。
如果仍上传失败，可临时设为 777 测试，确认是权限问题后再改回 755。
目录权限作用
data/755所有 JSON 数据写入（配置、留言、订单等）
uploads/755头像、背景、收款码、商品图、相册上传
data/software_files/755软件库二进制文件上传
其他所有文件644 / 755默认即可，不需要写权限
4
申请 SSL 证书（强烈推荐，开 HTTPS）
宝塔 → 站点设置 → SSL → Let's Encrypt 一键申请，然后开启 强制 HTTPS。
小程序 / AI 接口 / 支付回调 通常都需要 HTTPS 才能正常工作。
5
部署后第一件事：修改默认密码！
打开网站文件 api/login.php，修改前 3 行：
// 默认账号密码 —— 请立即修改！！
define('ADMIN_USER', 'admin'); // ← 改成你的用户名
define('ADMIN_PASS', 'admin'); // ← 改成强密码
define('JWT_SECRET', 'personal_homepage_default_jwt_secret_change_me'); // ← 改成随机长字符串
改完访问 https://你的域名/admin.html 用新账号登录即可。
1
确认主机支持 PHP
购买 Linux 虚拟主机 / PHP 空间，要求：
  • PHP ≥ 7.4
  • 支持 move_uploaded_file（一般都支持，除非极特殊锁权限的主机）
  • 支持 file_get_contents / file_put_contents 读写本地文件
2
FTP 上传到根目录（wwwroot / htdocs / public_html）
使用 FileZilla 等 FTP 软件把整个项目上传到主机的网站根目录，不要嵌套子文件夹。
3
控制面板 → 修改目录属性
在主机控制面板，把 data/ 和 uploads/ 目录设置为 755 或 可读可写（有些面板叫 "写入权限" 直接打勾）。
⚠️ 国内虚拟主机常见问题： 如果后台登录提示 500 或 "Unauthorized"，多半是 HTTP_AUTHORIZATION 没有被 Nginx/Apache 转发。 解决方案见下方 FAQ。

⚙️ 部署后必做配置

🔑 安全三件套（公网部署必改）：
① 修改 api/login.php 的 默认账号密码
② 修改同一文件里的 JWT_SECRET 为 32 位以上随机字符串
③ 开启 HTTPS（避免明文传输 token）

① 伪静态 / Nginx 配置（可选）

项目的入口都是 xxx.html 和 api/xxx.php，不需要任何伪静态规则，默认就能跑。
如果你的 Nginx 开启了 pathinfo 或防跨域限制导致 PHP 接口报 404 / 403，在站点配置里加一段：
# Nginx - 兼容 Authorization header（JWT登录用）
add_header Access-Control-Allow-Origin "$http_origin" always;
add_header Access-Control-Allow-Methods "GET,POST,OPTIONS" always;
add_header Access-Control-Allow-Headers "Content-Type,Authorization" always;
# 关键：让 Authorization 头传递给 PHP（虚拟主机常见缺失）
fastcgi_param HTTP_AUTHORIZATION $http_authorization;

② Apache / .htaccess（可选）

Apache 虚拟主机通常需要开启 mod_headers 和 mod_rewrite，如果登录 401，在根目录新建 .htaccess：
# .htaccess
RewriteEngine On
SetEnvIf Authorization .+ HTTP_AUTHORIZATION=$0
Header always set Access-Control-Allow-Origin "*"
Header always set Access-Control-Allow-Methods "GET,POST,OPTIONS"
Header always set Access-Control-Allow-Headers "Content-Type,Authorization"

❓ 常见问题 FAQ

打开页面显示 500 错误 / 空白？

90% 是 PHP 版本太低或语法错误。检查方法：

  • 宝塔：网站 → 设置 → PHP版本 ≥ 7.4
  • 直接访问 /api/profile.php?action=get，看报错信息，通常会告诉你哪一行错了
  • 极少数虚拟主机禁用了 JSON 函数，换用 PHP 8+ 即可
后台登录不上？输入admin/admin提示401或Unauthorized？

原因：Nginx/Apache 没有把 Authorization 请求头传递给 PHP（虚拟主机最常见）。

解决：

  • Nginx 站点配置里加：fastcgi_param HTTP_AUTHORIZATION $http_authorization; 然后重载
  • Apache 在 .htaccess 加：SetEnvIf Authorization .+ HTTP_AUTHORIZATION=$0
  • 或者直接改 api/login.php、api/profile.php 顶部的 authenticate() 函数，兼容用 GET 参数 ?token=（项目自带 authUrl() 已经支持）
后台上传头像/背景/商品图 都失败？

100% 是 目录没有写入权限：

  • 宝塔：把 data/ 和 uploads/ 权限设为 755，所有者 www
  • 虚拟主机：控制面板把这两个目录改成「可读可写」
  • 上传大小不足：修改 php.ini 里的 upload_max_filesize = 32M、post_max_size = 32M、memory_limit = 256M
contact.html 上传了自定义 HTML 不生效？

按顺序排查：

  1. 后台「联系设置」Tab 底部，右下角有没有显示 ✅ 已上传HTML文件 (xxx 字节)？如果没有说明上传没成功（参考上一条权限问题）。
  2. 点「👁 预览效果」会直接打开 uploads/contact_custom.html，看这个文件是否是你上传的内容（是 → 写入成功）。
  3. 再打开 contact.html，如果仍显示默认卡片：强制刷新 Ctrl+F5 或清除浏览器缓存（框架里有 Date.now() 时间戳，通常不会缓存）。
首页背景 / 音乐不显示？

背景图默认读取的是 static/img/background.jpg，如果你的文件不存在会 fallback 到纯色渐变。

音乐文件要放在 music/ 目录，必须是 .mp3 同名 + .lrc 歌词（歌词可以没有但要有mp3）。

上传到 GitHub 后，clone 下来会不会丢失商品？

不会。项目自带的 .gitignore 只忽略个人上传类目录（头像/背景/收款码/相册/音乐/软件二进制），以下内容会被 Git 保留：

  • ✅ 商品数据：data/shop/products.json
  • ✅ 商品图片：uploads/shop/*
  • ✅ 软件列表：data/software.json
  • ✅ 所有源码 / 默认图 / 字体 / SVG 图标

⚠️ 软件二进制文件 data/software_files/* 默认忽略，如需分发请自行添加或单独打包。

默认密码改完之后登录不上？

请在 无痕模式 下重新登录，或清除浏览器缓存（LocalStorage 里保存了旧的 token）。

确认 api/login.php 前两行：ADMIN_USER 和 ADMIN_PASS 是你想要的值，字符串闭合正确，没有多余引号。

能不能绑定到二级目录？比如域名/blog/

可以，但需要把所有 HTML 里的静态资源路径前缀（./static/、./api/）改成相对路径或正确子目录路径，工作量略大，推荐直接用子域名部署。

Personal Homepage
一个功能齐全、开箱即用的个人主页系统 —— 从展示、互动、变现到娱乐全部内置。
无需数据库，纯 PHP + JSON，部署只需上传文件 ✨
📖 查看部署教程 🔑 登录后台 📄 README.md

🧩 功能模块

🏠
首页展示
个人介绍、联系卡片、公告栏、背景图/头像自定义
🛒
自助商城
商品发布 + 卡密自动发货 + 订单管理 + 收款码配置
📷
照片相册
图片轮播、多种过渡特效、批量上传照片墙
📦
软件仓库
软件发布、版本管理、下载统计、卡密授权下载
🛠
在线工具
手机归属地 / IP详情 / QQ资料 / 身份证 / 抖音 等多接口聚合
💬
留言互动
访客留言板 + 访问统计 + IP归属地 + UA识别
🤖
AI 助手
本地问答库 + 兼容 OpenAI 接口的大模型双模式
💫
互动特效
3D 粒子互动墙、贪吃蛇小游戏、动态粒子背景
📞
联系页面
默认联系方式卡片，可上传自定义 HTML 100% 替换整页
⚙️
可视化后台
所有内容可视化配置，不写一行代码即可完整定制

🛠 技术栈

PHP 7.4+ (原生) HTML5 / CSS3 JavaScript (ES6+) JSON 文件存储 Glassmorphism UI JWT 鉴权登录 响应式布局 Canvas 粒子动效 无外部依赖 无需数据库
✨ 零依赖：所有静态资源（图标、字体、默认图、CSS、JS）都已内置在 static/ 目录， 部署到无外网环境的服务器也能完美运行，无需加载任何 CDN。

📁 目录结构

personal-homepage/
├─ index.html 首页
├─ shop.html 商城 · 自助购 / 卡密发货
├─ photos.html 相册 · 照片墙
├─ software.html 软件库
├─ tools.html 工具箱 · 多接口查询
├─ message.html 留言板
├─ contact.html 联系页 (支持上传HTML替换)
├─ game.html 小游戏合集
├─ particle3d.html 3D 粒子互动墙
├─ about.html ⭐ 介绍页 (本页)
├─ deploy.html ⭐ 部署教程
├─ README.md GitHub 介绍
├─ login.html / admin.html 登录 + 后台管理
│
├─ api/ 所有后端接口 (PHP)
├─ data/ 全部数据存储 (JSON)
│ └─ shop/ software_files/ ...
├─ uploads/ 用户上传资源
│ └─ shop/ ⭐ 商品图片（保留）
├─ music/ 首页背景乐
└─ static/ 全部静态资源（保留，不要删！）
